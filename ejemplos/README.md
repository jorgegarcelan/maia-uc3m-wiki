# Ejemplos de respuestas sobre MAIA

Esta carpeta recoge **preguntas típicas** y **ejemplos de respuesta** que pueden obtener estudiantes (o cualquier persona con acceso al repo) al usar la wiki MAIA junto con los agent skills de Cursor (por ejemplo `maia-wiki`, `plan-master`, `comparador-horarios`).

Sirven como referencia de **qué tipo de información** se puede sintetizar y **en qué formato** suele presentarse.

> Los contenidos usan la edición **2026/2027**, revisada el 24 de agosto de 2026. Las normas y cambios posteriores publicados por la UC3M prevalecen siempre.
