# Figuras MAIA Wiki

SVG estáticos que sustituyen a los diagramas de código en los artículos de `wiki/`.
Siguen el sistema definido en `DESIGN.md`: Varela Round con fallback de sistema, paleta
navy/azul/violeta, radios de 8–18 px y sombras frías.

Se referencian desde markdown con ruta relativa (`../public/figuras/…`) para que
funcionen en GitHub; la web reescribe la ruta a `/figuras/…` al renderizar.
