# MAIA Wiki — Consulta general

Responde usando **solo** la documentación de este repositorio (`wiki/`, `ejemplos/`). La **UC3M** es la fuente de verdad para normativa, fechas y precios; si la wiki y la web oficial discrepan, indícalo y prioriza lo oficial.

## Cuándo usar esta skill

- Dudas amplias: “¿cómo funciona el máster?”, “¿cuántos ECTS?”, “¿qué becas hay?”
- No sabes si hace falta `plan-master`, `comparador-horarios`, etc. (puedes sugerir la skill adecuada al final).

## Qué hacer

1. Identifica el tema y **lee** los archivos relevantes (no inventes códigos ni fechas).
2. Responde en **español**, claro y estructurado (tablas o listas si ayuda).
3. Cita rutas wiki (`wiki/...`) o enlaces oficiales UC3M cuando existan en la wiki.
4. Curso de referencia: **2025/2026** salvo que el usuario indique otro.
